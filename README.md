# Cahier — Global BBA

Classeur de cours personnel : écriture des cours, import et classement
automatique des documents, OCR des photos, et agent IA calibré sur le
niveau 1re année du Global BBA de l'ESSEC.

Application autonome, un seul fichier (`index.html`). Aucune donnée n'est
envoyée nulle part sans action explicite : les cours vivent dans le
stockage local du navigateur, et la clé API — saisie dans ⚙ Réglages —
reste elle aussi sur l'appareil.

## Moteurs IA

Au choix dans les réglages, avec la clé correspondante :

- **Gemini (Google)** — palier gratuit disponible ; clé sur aistudio.google.com
- **Claude (Anthropic)** — payant à l'usage ; clé sur console.anthropic.com

Le bouton « Lister » interroge le fournisseur pour afficher les modèles
réellement disponibles avec la clé, plutôt que de dépendre d'un nom figé
dans le code.

## Sauvegarde

⚙ Réglages → « Exporter en JSON » produit une copie complète du classeur,
réimportable sur n'importe quel appareil.
